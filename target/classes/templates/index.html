🐙 GitHub MCP Agent (Java)

Explore GitHub repositories with natural language. This Java version runs the GitHub MCP Docker server and captures its output.

${error}

How to use

  1. Install Docker and Maven
  2. Set `OPENAI_API_KEY` and `GITHUB_TOKEN` environment variables or provide them in the form
  3. Click "Run Query" to run the MCP Docker container and capture output
